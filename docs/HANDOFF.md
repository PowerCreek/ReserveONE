## Decisions / defaults taken (T10)
- Spec ambiguity: 3m cadence applies only to waiting items; READY_NOW items stay at wait 0.
- Occupied units never "ready now": availableAt clamped to >= now+5m.
- Link-group slot is created on the first table id only; other members are occupied without a slot.
- Queue entries consumed by status `SEATED` (kept in data, filtered from lists).
- Header "to bus" = tables with status `lapsed`. Bus priority remains the spec stub.
- Canvas size fixed 1200x720 (presets deferred). New waiters get `max_covers=18` on load.
- Inspector label edit pushes one history snapshot on focus (no-op copy).

- Gantt: slots only on primary table of link group; range fixed at mount (-6h/+36h); header cells memoized per minute.
- Staff: `skip_penalty` (300) cleared for all servers on next seating anywhere; shift check uses local clock; removal reassign moves cover count + assigned tables.
- Middle-mouse fix: native `mousedown`/`auxclick` preventDefault on SVG (kills browser autoscroll) + `onLostPointerCapture` ends gesture.
- Reservation edit form reused for add; table capacity validated against party size.

## M5 decisions (read before changing)
- Sections = server-earmarked table groups (`table.section_id`), assigned ONLY via Inspector. Bubble = line-of-sight graph (`src/blobs.ts`): same-section tables connect if the centre-to-centre segment misses every non-member table (+8px slack), at any distance; the fill is the convex hull of all members when every member sees every other (clique), else a hull per visible pair/triple (gaps between tables are filled, not just traced), rounded by a PAD-wide stroke, inside a mask, other-section tables cut out. A section whose tables split into >1 LOS component is 'fragmented': ALL its bubbles render with a dotted texture (pattern `dt_<id>`), never one solid + others dotted; a fully-visible section keeps one solid bubble. Components that can't see each other are chained with dotted 'wires' (nearest pair, Prim). Uses committed positions (updates on drop).
- Section underflow = occupancy < min_occupancy (default 20%) AND turns due in 30m < need (min_turns, else 25% of tables, >=1). Defaults make the seed patio underflow (demo); alerts are edge-triggered with baseline pass.
- Labels via `partyLabel`: `[prefix,type,id]` joined by '-' (empty prefix => `W-7`). `relabel()` migrates stored slots on load.
- Staff: no clock-in/shifts; every roster server is eligible (`is_active` stays true, hidden). Future shifts screen should set `is_active` for the day's pool. Edit/skip/end-of-rotation/assign/remove-with-reassign retained.
- Day model: `ctx.day` (transient, not persisted) drives Gantt window (day 00:00 -> +30h) and Reserve view; sidebar compact lists and seating are always today. Seating a reservation booked for another day is blocked.
- Gantt: `gint` seconds = tick + slide cadence, `gan` % = NOW anchor (both persisted). Rows show only tables with slots/reservations/events overlapping the day unless 'All tables'. Non-today days scroll to 10:00.
- Audit: reducer-level `diffAudit` over id-keyed collections (tables, slots, reservations, queue, waiters, events, sections, floors, links); rapid updates to one record coalesce (4s) keeping the first `from`; flashes/alerts logged as entity `ui`; system actor for reconcile/integrity; undo/redo annotated. Not part of undo history. Cap 1500, persisted in localStorage.
- Panels: `Panel` (ui map persisted in prefs): collapse + pin; pinned ignores collapse-all (header ⊟/⊞). Drawer state is `prefs.drawer {ids,active,open}`.
- Dock is `position:sticky; bottom:0; margin-top:auto` inside `.app` (visually fixed to viewport bottom, aligned to container width).

## UI guidelines (carry forward)
- **U1 No line-breaking of operational data.** Times, ETAs, labels, counts, badges, statuses, table/party ids, buttons never break mid-value. Pattern: a flex container (`.entry`, `.row.wrap`) wraps BETWEEN items; every datum is its own unbroken element (`span`/`b`/`.badge`, `white-space:nowrap`; long ones may ellipsize in fixed-width cards). Only prose (`.prose`: notes, help text) may wrap. Never use `overflow-wrap:anywhere` on shared containers.
- **U2 One way per action.** Each outcome has a single home; other places link/open it (e.g. ResList 'Book'/'Edit' open the Book widget). Single homes: reservation create/edit = Book widget; walk-in queue add = Fast seating; undo/redo = header; table section = Inspector; server assignment = Staff panel; events = Events panel; delete of reservations/queue entries = explicit buttons (no double-tap; double-tap remains only for removing N-top sequence cards).
- **U6 Layout conventions:** collections of people/things users compare (servers) are card rows (`.cards/.scard`, horizontal scroll), not data rows; 'add' controls use the accent `.addbtn` theme and come FIRST in their control list (drawer ＋ precedes the tabs).
- **U3 A widget lives in one place** (sidebar or drawer). `Panel` handles ⤓/↥; drawer-only tools (N-top, Book) are added/removed via ＋. Don't assume which widgets a user wants; keep the registry (`components/widgets.tsx`) the single source.

- **U5 Tab-scoped content stays in its tab.** Anything a widget contributes to the drawer bar (e.g. the N-top 'Next:' line) renders only while that widget's tab is active.
- **U4 Quick actions show what they touch.** Before: Fast seating shows a preview box (auto + selected targets: table(s), server, section, turn); queue/reservation Seat buttons read `Seat → C3 · Lee`; hovering pulses the target table(s) on the canvas (`ctx.pv`). After: a receipt bar (`ctx.receipt(title,refs)`) lists party/table/server/section/turn etc. with 📍 jump and ↶ Undo, is logged to the audit, and pulses the tables 6s. Receipts exist for: seat (auto/selected/queue/reservation), add to queue, priority promote, assign table, reservation status, clear table, +15m turn. Implement via `previewSeat`/`seatRefs` (state/entries.ts) and `Receipt.tsx`; new quick actions must do both.

## Linking decision (supersedes any adjacency rule in SPEC.md)
- Link groups have NO positional rules: any tables may be linked at any distance, groups are never auto-split when members move, no 'must touch' alert. Only constraint: members must be on the same floor (units, canvas and evaluator are per floor). `normalizeAssociations` only drops deleted tables / dissolves groups with <2 members / repairs a missing primary.
- Canvas draws non-touching members with dotted wires to the primary; dragging any member still moves the whole group.

## M12 decisions (1:1 sections, simulation, tap-to-act, audit)
- **Sections are 1:1 stations by default, open-ended on purpose.** Seed: Maya→A, Dev→B, Sam→C, Lee→Patio; A5 is a 2-top so equal-fit ties exist across stations. Sections panel: 'Server' select REPLACES (exactly one server), '＋ share with…' adds extra servers, chips remove them; badges `no server` / `shared ×N`. Creating a section can assign its server. Staff cards flag `no section` (fallback server only). Existing saves keep their own data (Reset data shows the new demo).
- **Rotation-aware table choice** (`planSequence`, src/predict.ts): tightest fit still wins; among equally-tight tables the one whose server is next up wins; unsectioned/fallback tables lose ties; waits are unchanged (pref only breaks ties among free tables; delayed picks stay (capacity, earliest) first). Used by `seatParty` auto, the N-top pane, Queue ETAs and walk-in quotes (so labels agree). The N-top lookahead *tiles* still use the plain evaluator (counts only).
- **Simulation** (src/sim.ts, simclock.ts, components/Simulation.tsx): entering snapshots real data (real key untouched), all edits persist to a separate key `host-seating-planner:sim:v1` (data + snapshot + clock offset + prefs; resumes after reload). Exit & discard dispatches `reset` with the snapshot; Exit & keep is disabled once the clock moved. Clock = global `Date` Proxy (`Date.now()`/`new Date()` shifted by an offset) so the whole app time-travels with no per-call changes; advancing optionally runs `settleOverdue` (parties leave at turn+5m, `ended_at` set accordingly). Generators are parameter-driven + seeded (walk-ins → queue, reservations with best-fit conflict-free tables, 'fill dining room' via the REAL allocator with staggered seat times). Generators only render while simulating, so real data can't be fabricated by accident. `markAvailable(d,sel,endedAt?)`.
- **N-top cards are actions:** tap = READY → seat at the planned table(s) now; otherwise → add to Queue with the quote (queue ahead included), planned table + clock and predicted server (`Plan:` note), receipt with Undo. Card removal is the ✕ (no more double-tap).
- **Audit readability:** `humanValue/fieldLabel` (src/auditfmt.ts) render ids as names (server/section/table/floor), null as `none`, ISO as clock, id arrays as names; raw ids kept in storage. Each `.arow` scrolls horizontally on its own (the list doesn't).

## M14 decisions (arrivals, door list, mark ahead, free-typing numbers)
- **Partial arrivals** (src/arrivals.ts): `Reservation.arrived_count/arrived_at`, `QueueEntry.arrived_count`. `hereRes` defaults by state (BOOKED 0; ARRIVED/SEATED/QUEUED = everyone) unless a count is recorded; walk-ins default to everyone. `setArrived/addArrived` (entries.ts): first guest → ARRIVED (+arrival time), back to 0 → BOOKED, a no-show who turns up → ARRIVED; a promoted queue entry delegates to its reservation and mirrors back. State chips: ARRIVED = everyone here, BOOKED = nobody. **Seating a reservation** (`seatParty`) → SEATED and stamps arrival: everyone here unless a partial count was recorded (kept, so the host still watches for the rest). `expectingMore` feeds the **Expecting** panel, card `HereRow` (− ＋ all here), header `⏳ N to come`, and the seat receipt's `Still to come`.
- **Simulation door list** (SimEntry in `Data.sim`, sim.ts, SimEntries.tsx): entering auto-populates it (`genStarter`); generators stage guests with arrival times instead of writing to the queue. `walkin` entries → **→ Queue** via the shared `addToQueue` (ids `q_<entryId>`; parties of 2+ may arrive in waves: later `arrive` entries join the queued party), `arrive` entries → **Arrive** (+n here) on a reservation/queued party; `✕` = turned away/no-show; due = arrival time <= now (clock advance reveals more). Discarded with the snapshot on exit.
- **Mark ahead** (src/ahead.ts, Fast seating 'Seat now | Mark ahead'): pick date/time (hours or days) + length; **Auto-mark best table** = tightest conflict-free unit on any floor (reservations, private events, seated parties; manually blocked tables skipped), **Mark selected table** validates capacity/conflicts (linked groups held as a unit). Creates a held BOOKED reservation for a new party, or sets table/time/length of the active reservation. Not available for queued parties (they are seated now).
- **`addToQueue`** is the single way to queue a party (Fast seating, N-top card tap, door list).
- **U7 Numeric fields are free-typing:** use `NumInput` (components/NumInput.tsx, helpers in src/numinput.ts), never `<input type=number>` with an inline clamp/default. While typing, empty/partial text is allowed and only in-range numbers commit; on blur/Enter empty/invalid restores the previous value and out-of-range is clamped. Pure helpers `typed/settle` are unit-tested.
- Seat buttons target the current table SELECTION first (label shows the target, U4); clear the selection to auto-allocate.

## M15 decisions (selection, unseat, hover, help)
- **Selection is advisory, never silently wrong.** `src/selection.ts selectionState(d,sel,size,partyId)` → none/free/small/joining/occupied/lapsed/blocked. `seatModeFor(A,req)` (state/entries.ts) uses the selection only when it is `free`; otherwise the smart allocator is used. All quick Seat buttons (`SeatBtn`, `seatRes`, `seatQueue`) share it, so the preview always matches the action. A successful seat at the selection clears it.
- `seatParty` errors name the table: `X is blocked (private event)`, `X is occupied by another party`, `X is past its turn: clear it first` (a lapsed table must be cleared before seating; lapsed tables used to be seatable and left a stale slot).
- **Clearing has one implementation**: `clearTables(A,sel)` (Inspector 'Mark Available', TableCard '🧹 Clear (party left)', Bus list '🧹 Clear table'). `clearAndSeat` = clear + seat in one undo step.
- **Unseat → queue** (`src/unseat.ts unseatToQueue`): slot is deleted (it never happened), tables freed, server `active_cover_count` and `tally_covers` returned. Reservation → QUEUED + priority entry; a previously SEATED queue record → WAITING; bare walk-in → new queue entry. **Unqueue → door** (`unqueueToDoor`, simulation only): walk-in → door entry; reservation → BOOKED, not arrived, door `arrive` entry.
- `src/door.ts`: `enqueue` is the one queue-entry constructor (addToQueue uses it); `seatOrQueue` seats at the best ready table only when the whole party is here AND nobody is waiting, else queues (partial parties wait for the rest); `processDoor` runs every walk-in whose time has come. The Door list has ⚡ per guest and ⚡ Process everyone.
- **FixedTop** (components/FixedTop.tsx): one fixed top-right parent stacks the sim status (`SimBar`, collapses to the 🧪 `.simdot`; state in `ui.simbar.c`) above the table locator, so they never overlap. Do not add other `position:fixed` widgets at top-right; add them to FixedTop.
- **U8 Every container explains itself:** add its entry to `HELP` (components/Help.tsx); `Panel` and the drawer render the ⓘ automatically from the id. Popover is fixed-positioned (opens upward near the bottom).
- **U9 Table references are hoverable:** put `data-tid={tableId}` on anything that names a table (canvas `<g>`, receipt chips, badges, Gantt labels); `HoverCard` shows capacity, section, server, party (label, name, here/size, arrived/seated/turn, reservation time) or the reservation holding it. Mouse/pen only (touch uses the 📍 locator).
- Canvas tags (`.ttag`): drawn under the OWNING table of a seated party (slot table) or hold (reservation table): `LABEL · Name ×size` (partial `here/size`), `📅 time Name ×size` for holds. `src/tableinfo.ts tableInfo` is the single source for tags and hover card.
- Gantt: `ppm=60/gz` (zoom chips 5/10/15/30/60 min), NOW = full-height `.gnowline` inside `.ginner` plus a `NOW h:mm` tag in the sticky header, update interval min 1 s, anchor 0–100% (scroll set whenever it differs by >0.01px).
- h3 in `.phead` is `display:flex; overflow:visible` so badges inside titles (Simulation [ON]) do not get their borders clipped.

## Reservation states (any → any)
- Every reservation card has five state chips (Booked / Arrived / Seated / No-show / Queued) in full and compact lists; the current one is highlighted. Any state can be set from any other as human-error recovery (`setResStatus`, src/state/entries.ts), with a receipt + Undo. It replaces the one-off Arrived / No-show / Reopen buttons and the status select in the Book wizard (U2: one home for status changes).
- Rules: **Queued** chip = the real priority promotion (creates the queue entry); leaving Queued **withdraws** its waiting queue entry; **Seated** is status-only (receipt notes 'table/server unchanged'; use the Seat button to actually seat); same-state click is a no-op. Seating a promoted entry from the queue now marks its reservation Seated (`queueReq` carries `resId`).

## N-top predicted rotation (src/predict.ts, components/Predictor.tsx)
- `predictRotation(data,items,units,now)` replays the tally rotation over the sequence the N-top pane is showing: per item `pickServerFor(rotation(ws…))` for that unit's tables, then that server's tally += party size (and `skip_penalty` cleared for all, mirroring `seatParty`), so later parties see earlier ones. Cards show `→ Server before→after` (`fb` = fallback server); the strip under the tiles shows standings after the sequence with `+gain` per server (reads 'now' with an empty sequence); the drawer bar line uses the same prediction for item #1. First pick is unit-tested to equal what `seatParty` really assigns.

## Turnover panel decisions (src/turnover.ts, components/Turnover.tsx)
- Interval = any multiple of 5 min >= 10 (chips 10/15/30/45 + select to 120), buckets aligned to local midnight; 3 past + current + 5 future rows. Tables = parties (a linked group counts once).
- Observed = `seated_at`/`ended_at` <= now; projected (shown `~`, italic) = occupied tables' `expected_turn_at` (overdue/lapsed project to now) and BOOKED/ARRIVED reservation arrivals (late ones project to now). Queue entries are not projected into buckets (shown as a chip).
- 'Bifurcated' walk-in script: ① WAIT = `walkinQuote` (evaluateSequence over ALL floors for [queue ahead..., new party]; quote window = 5-min floor of wait to +10 min; 'ready now' if 0; 'none' if no table fits) and ② TURNOVER = projected outs/ins in the next interval + next-free time of a 1-top. Both give a ready-to-read sentence.
- Queue order now has one home: `queueOrder` (turnover.ts), used by the Queue panel and the quotes.

## M8 decisions
- **No table/cover cap per server** (`max_covers` removed from model/UI; old saves have it deleted on load). Staff cards render in rotation (tally) order, same as the top strip, with a 'next up' badge, tally marks + count, open covers, last-seated time (the tie-breaker). Top strip and staff cards share the spaced layout (`.rcard`/`.scard` flex column, tally in a `.row`).
- **Bus priority** = spec §6 `demand*10 + 22.5 + 8` EXTENDED with the tally rotation: `+5 × (servers − rank position)` of the server who would receive the next party at that table (`pickServerFor`), so next-up servers' tables are cleared first; ties by dirty minutes. Entries show `Name #rank`.
- **Rotation (src/engines.ts `score`)**: rank = −tally_covers + idle/1000 (idle capped 600m so it only breaks ties) − skip_penalty; inactive −99999. Tally = cumulative covers seated this service (party of N adds N; never decremented by clears; clears only drop `active_cover_count`). Incoming reservations and open covers are NOT used. `pickServerFor` still prefers the best-ranked server covering the table's section. New server starts at the current minimum tally; ± buttons correct a tally; 'New service' zeroes all. Reassigning tables moves covers + tally. `rotation(ws,_t,_r,now)` keeps its old params for call-site compat (unused). 'End of rotation' was removed (redundant).
- **Slot.ended_at** is stamped by `markAvailable`; the Ledger uses it for clear events (older completed slots without it show no clear event).
- **Locator**: ctx `lref` (ids expanded to link groups) is set by `focusTable` and receipts; the fixed top-right pin opens a modal `Canvas local floor mark init` (own zoom/pan, shared data/selection). While it is open the main canvas ignores the keyboard. Mask/pattern ids are per-floor (`bm_<floor>_<section>`).
- **Pinch**: two pointers → `pinchView` (src/pinch.ts); also gives two-finger pan. Single-finger on empty canvas is still marquee (use Pan tool to pan with one finger).
- **Gantt scroll**: `.gscroll` uses `overscroll-behavior-x:contain; -y:auto` and `max-height` so vertical swipes/wheel chain to the page.
- **Drawer**: ⚙ menu = move to sidebar / remove, move tab left/right, collapse. Docked panels leave a stub (`.stub`) in the sidebar with Open / ↥ Restore. Ledger is a normal dockable panel.
